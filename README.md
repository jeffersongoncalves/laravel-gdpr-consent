# GdprConsent

GDPR consent ledger for Laravel: append-only proof of consent per purpose and version (Art. 7), withdrawal as easy as giving it, expiry, anonymous visitors claimed on login.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/laravel-gdpr-consent
```
